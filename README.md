# WorkFlow API

A robust task management system built with Spring Boot to help teams organize their daily work, track progress, and collaborate effectively.

---

## User Stories

1. **User Registration & Profile** > **As a** new developer,
   > **I want to** create a personal account with my email and role,  
   > **so that** I can be assigned to specific projects and track my own tasks.

2. **Task Creation & Prioritization** > **As a** project manager,
   > **I want to** create new tasks with a title, description, and priority level (Low, Medium, High),  
   > **so that** the team knows exactly what needs to be done first.

3. **Status Tracking** > **As a** team member,
   > **I want to** move my tasks through different stages (TO DO, IN PROGRESS, DONE),  
   > **so that** everyone has real-time visibility into the project's progress.

4. **Assigning Tasks** > **As a** team lead,
   > **I want to** assign a specific task to a registered user,  
   > **so that** responsibilities are clearly defined and no task is left unowned.

5. **Deadline Management** > **As a** user,
   > **I want to** set and view due dates for my tasks,  
   > **so that** I can manage my time effectively and avoid missing important deadlines.
